# Dad Memory Gallery

Upload your photos into this folder. The birthday website automatically lists supported image files from this directory.

Supported formats: JPG, JPEG, PNG, WEBP, GIF, AVIF, HEIC, and HEIF.

- Keep the original photo filenames if you want.
- The gallery puts `dad-memory.jpg` first when that file is present.
- Other photos are sorted by filename.
- This folder currently contains no photos; add your photos here when you're ready.
